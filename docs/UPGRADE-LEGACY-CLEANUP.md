# 旧版本自动清理与完整卸载

## 新版安装（默认自动执行）
- 在安装资源清单验证通过、仅识别本程序旧进程并安全停止后，根据旧版 `install-files.json` 和明确的旧组件名，识别 **当前新版清单不再包含的程序文件**。
- 新版安装会先备份现有程序文件和待删除的旧版程序文件；文件复制及校验完成后才清理旧组件。文件复制、校验或删除失败时恢复原文件，不以“先运行旧卸载器”替代事务升级。
- 清理上一次原版任务遗留的 `monitor-playback-<token>.json`、`monitor-zhs-<token>.json` 等严格限定名称的临时状态文件，不解析或泄露原始通信。
- 识别 `%TEMP%` 下符合本程序命名规则、超过 **24 小时**的旧安装解压目录和临时包；明确跳过当前正在运行的安装目录、其他软件的目录和目录链接。
- 清理只能确认目标指向本程序安装目录的旧快捷方式及注册项；创建/覆盖当前版本的桌面快捷方式与卸载注册项。

**升级默认保留**：`%USERPROFILE%\.zhs`（第三方 ZHS 的 Cookie 和课程数据）、`%LOCALAPPDATA%\ZHSDesktop\.venv`（可复用的私有 Python 环境）、`uv.exe`、`official-webview-profile`、用户课程缓存和不在旧包清单内的自建文件。

## Windows 系统卸载
在“设置 → 应用 → 已安装的应用”卸载本程序时，通过安装目录中的 `Uninstall.ps1`：

1. 验证安装目录不是重解析点，定位并安全结束**本程序归属**的进程；不按通用 `powershell.exe`/ `python.exe` 的进程名杀进程。
2. 移除整个专属应用目录 `%LOCALAPPDATA%\ZHSDesktop`：包括历史文件、私有 Python 运行环境、可删除的应用缓存、WebView2 专属用户配置等。
3. 移除只有**目标路径确认为本程序**时才允许删除的桌面/开始菜单旧快捷方式，及只有 **InstallLocation 确认为本程序目录**才删除的注册项。
4. 清理超过 24 小时、命名规则匹配的程序安装临时包。无法安全判定归属的文件保留并报告警告。

**不会自动删除**共享目录 `%USERPROFILE%\.zhs`：其中可能有明文 `cookies.json`，也可能被其他 ZHS 工具复用。即使传入旧 `-RemoveZhsData` 参数也会拒绝删除，防止升级/卸载损坏其他应用。

## 范围与验证
- Windows PowerShell 5.1 `test_legacy_cleanup.ps1` 使用完全隔离的假安装目录、假快捷方式和专用测试注册键，验证旧版文件列表、私人文件保留、临时清理时效、当前安装目录保护及目录归属识别。
- 原有 Manifest、离线 Python、WPF、Windows PowerShell 5.1、安装器构建测试仍需通过。
- 目前自动化测试不等于在用户真实电脑上完成旧版迁移和完整卸载。用户可先安装新包以验证自动升级；实际卸载会删除本程序的浏览器登录状态和私有运行环境。

## 恢复与限制
- 如果升级途中程序文件复制失败，自动尝试恢复旧文件，并留下无法成功回滚的备份路径以供诊断。
- 不删除全局 uv/Python、其他程序共用缓存或名称含糊的目录。
- 如果在正式卸载时用户将其他数据手动放入该应用专属目录，这些数据也将随该目录被删除；应在卸载前自行备份。
