# Windows 旧版自动清理与彻底卸载（2026-11-14）

## 正常升级：自动替换 + 清理

安装新版时，先验证资源清单，再只关闭该安装目录下可识别的知到助手进程。继续原有 Python/ZHS 版本核验、文件哈希、分阶段复制和失败回滚。**不会先执行旧卸载器或删除整个旧目录**，从而避免升级中途失败导致旧程序及登录态全部丢失。

成功替换后，自动清理已审核的旧启动文件 `ZHS-GUI.ps1` 与 `ZHS-CLI.cmd`、超过两天的临时监控快照、超过七天且名称符合已知规则的知到助手安装临时目录。已知残留包括 `zhidao-setup-*`、`zhidao-app-stage-*`、`zhidao-app-backup-*`、`zhidao-uv-*`。**不会扫描任意路径或广泛删除用户临时文件**。

正常升级保留：
- `%LOCALAPPDATA%\ZHSDesktop\.venv`、`uv.exe` 和现有可用的运行依赖；
- 应用课程缓存、设置、Cookie、官方 WebView2 登录数据；
- `%USERPROFILE%\.zhs` 内 ZHS 上游共用的课程及账号数据；
- 未列入可安全删除名单的未知用户文件。

升级完成后如遇清理失败，安装器发出警告但不撤回已经安装成功的应用，也不会因为清理失败重启心跳/学习任务。

## Windows 设置中的普通卸载

从“已安装的应用”卸载时，先安全关闭本程序所属的进程，然后卸载：
- `%LOCALAPPDATA%\ZHSDesktop` 整个应用专用目录（包括应用 Python 虚拟环境、内嵌网页缓存、诊断文件和应用 Cookie）；
- “知到学习助手”桌面快捷方式；
- 当前用户的应用卸载注册表记录；
- 超过七天的知到安装器临时残留（不会动其他软件的临时目录）。

仍**保留**上游所有 ZHS 工具共用的 `%USERPROFILE%\.zhs` 文件夹，因为它可能包含其他程序仍在使用的 Cookie/缓存。若扫描到符号链接/目录联接，清理将拒绝递归删除并显示错误，以保护外部文件。

## 明确选择彻底清除共享 ZHS 账号数据

如确认 **不再使用任何依赖 `%USERPROFILE%\.zhs` 的工具**，并已自行备份，可以从 PowerShell 手动执行：

```powershell
& "$env:LOCALAPPDATA\ZHSDesktop\Uninstall.ps1" -RemoveZhsData
```

此模式显示共享数据删除风险，并要求逐字输入 `DELETE SHARED ZHS DATA`。未输入正确文字时**不会开始卸载**。正常安装/升级不会设置这个参数。

## 验收限制

Windows PowerShell 5.1 的离线测试使用模拟安装目录验证清理范围，CI 不运行真实卸载，也不接触账号凭据。通过 CI 不代表在用户电脑已清除全部历史版本；未知的第三方安装目录、系统级旧安装器和用户手动存放的 EXE 不会被自动删除。
