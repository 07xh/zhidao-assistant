知到学习助手 V5.2.8 · 官方 WebView2 自动连续播放（测试版）

新功能
1. 课程详情可以设定官方播放器速度（默认 1.5×，支持 1.0/1.25/1.5/2.0）。
2. 选择“允许最小化”后，播放器会显示一键最小化按钮。
2a. 新增“进入视频后自动播放”和“本节结束后自动下一节”，均可独立启用或关闭。默认开启，仅对已进入的官网视频页生效。
3. 官方学习页在 WebView2 独立窗口打开；登录需在官方网页完成，与 ZHS Python Cookie 不共享。
4. 只处理真实播放的 HTML5 <video> 元素，不自行报告或模拟学习进度。
5. 若无 WebView2 依赖，则明确提示并改用系统浏览器，此时倍速需手动选择。
6. 课堂服务器进度核验仍可在课程详情中独立进行。

重要限制
- 后台最小化窗口不保证继续播放：系统/浏览器/知到可能限制后台媒体播放。
- 自动开始可能被浏览器策略阻止；视频结束后只有识别到明确的“下一节”等按钮才会尝试切换。
- 自动播放不代表考试或任务点自动完成；只处理网页提供的真实视频播放控件。
- 官方网页版若未使用可访问的 HTML5 video，1.5× 设置可能不生效。请在官方播放器内核对。
- 课程地址只能从实际登录课程 ID 构造，AI 智慧课程使用 courseId/classId，普通共享课使用服务器返回的 recruitAndCourseId 路由标识打开官方课程页；如果旧缓存缺少该字段，需要重新同步课程。
- 本版只在 Linux 上对 XML、包内文件和 Windows PE 进行了静态检查；未用真实课程在 Windows 真机联调。
- V4.4 既有 ZHS 原版入口未修改；官方模式不会额外发送模拟心跳。
- Windows 安装器需要联网安装 zhs==0.1.5 和 Microsoft WebView2 SDK（固定 NuGet 版本 1.0.4191.47）。WebView2 Runtime 如未安装需要从 Microsoft 官方渠道获取。
- 本软件第三方非官方；注意知到账户安全、课程规范以及 GNU GPLv3 授权要求。

常见问题
问：设置 1.5× 后没有变化？
答：可能是跨域嵌套播放器或专有播放控件，点击播放窗口顶部“尝试 1.5× 倍速”，再使用官方播放器内的倍速菜单确认。
问：最小化后是否能一直播放？
答：无法保证。软件不绕过浏览器后台限制，也不会在暂停时伪造观看记录。
问：官方模式和 ZHS CLI 是否共享登录？
答：不共享。WebView2 单独保存在 %LOCALAPPDATA%\ZHSDesktop\official-webview-profile。


安装与升级
1. 在电脑上关闭旧 V4.4、V4.2 的所有学习助手和播放窗口。
2. 双击 ZhidaoAssistant-Setup-v5.2.8.exe；安装器需要联网获取缺少的运行依赖。
3. Windows 桌面图标名称保持不变；本版不会主动删除 %USERPROFILE%\.zhs 的课程缓存和登录文件。
4. 打开后在“课程详情”选官方模式、1.5×、允许最小化，点击“打开官方播放窗口”。
5. 第一次 WebView2 官网页面需要单独登录；播放后在应用内核验服务器进度。
6. 卸载可使用 %LOCALAPPDATA%\ZHSDesktop\Uninstall.ps1；默认保留个人目录数据。

ZHS 原版模式仍保留旧 V4.4 调用，未修改第三方原版源代码。此模式可能提交模拟学习记录，和官方播放不同。

V5.2 新增：播放器在官方 HTML5 video 触发事件后显示实际播放倍率和播放状态（仅本机状态，不额外发送进度请求）；正常关闭播放窗口后自动只读核验打开时选中的课程。若外部浏览器回退，仍需手动核验。

V5.2 修复与真实课程验收
- 普通共享课现在使用从 ZHS 课程列表中读取的路由标识进入官方课程页。旧缓存缺少路由标识时必须重新同步课程。
- 智慧课程列表单条记录损坏不再隐藏其余有效课程；全部记录异常时保留旧缓存。
- 网络/登录/数据结构异常分别输出分类错误码；不会打印原始异常、请求 URL 或 Cookie。
- 关闭播放窗口后排队执行该课程只读进度核验；后台核验未完成时阻止清除缓存。
- 完整运行前提：Windows 10/11 x64，已经登录的 ZHS 0.1.5 会话，官方 WebView2 能打开对应课程页面。
- Windows 先运行 %LOCALAPPDATA%\ZHSDesktop\Windows-Preflight.ps1 进行无敏感信息的本机自检。
- 真实课程必须在官方页面由本人正常播放，关闭窗口后观察官方知到 App 前后学习进度。不能把本地倍速或本地知识点比例当作官方完成证明。
- 此版本尚未获得 Windows 真机和本人真实课程的端到端证据，勿作为正式版分发。
- 卸载默认删除应用及 WebView2 网页登录资料，但保留 %USERPROFILE%\.zhs（包含明文 Cookie）；必须由用户明确决定是否删除共享 .zhs 数据目录。uv 管理的 Python 可能保留。

V5.2.8 自动播放验收：先进入本人真实课程，确认 HTML5 视频实际开始播放，再等待本节自然播放完毕，核对是否进入下一节；如官网禁止自动播放或按钮识别失败，请手动操作。不访问或改写学习心跳 API，进度以服务器记录为准。

V5.2.8 修复：首次同意标记在 GUI 与命令行任务入口统一；自动播放仅作用于顶层页面选定的单一主视频，iframe 不自动控制；自动播放请求有 pending 锁和有限重试；自动下一节仅在明确课程主内容容器内识别，找不到则要求手动切换。
