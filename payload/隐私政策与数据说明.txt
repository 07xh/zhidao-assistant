知到学习助手 V5.2.7 · 隐私与本地数据处理说明
版本：5.2.7；发布日期：2026-11-11

1. 谁在处理数据
本程序是第三方非官方 Windows 工具，不设置开发者自建服务端、遥测统计或广告追踪。知到共享课数据请求通过 ZHS 开源依赖直接发送至智慧树服务；安装器会联系 GitHub、uv/Python 和 PyPI 相关下载来源。

2. 登录方式
知到 App 官方扫码确认，或者由用户主动选择本人已有的 ZHS cookies.json 导入并验证。软件不会要求在自己的界面输入知到账号密码；但 ZHS 会获得用户会话 Cookie，可用于代表用户登录，因此该文件属于敏感凭证。

3. 本地文件位置
%USERPROFILE%\.zhs\cookies.json — 会话 Cookie，目前仍由 ZHS 保存为明文 JSON；V4 未实现 DPAPI 加密。
%USERPROFILE%\.zhs\qrcode.png — 扫码登录二维码。
%USERPROFILE%\.zhs\zhidao-courses.json — 本人知到共享课和智慧课程名和 ID。
%USERPROFILE%\.zhs\zhidao-progress.json — 本人课程的视频时长、学习时长及服务端完成状态。
%USERPROFILE%\.zhs\config.toml — ZHS 本地配置。
%USERPROFILE%\.zhs\logs\ — ZHS 日志，可能含敏感请求信息，请勿外传。
%LOCALAPPDATA%\ZHSDesktop\privacy-accepted-v5.2.7.flag — 已阅读并同意本版告知的时间标记，不含账号信息。
较旧版本和原版 ZHS 可能保存其他数据文件，本程序不会自动清除。

4. 首次使用同意
V5.2 首次启动时显示本声明与第三方使用条款，并要求主动勾选。不同意则退出，不运行登录与数据查询。从 V5.1 或更早版本升级到 V5.2 时也需重新确认。

5. 本地数据清理
“退出并清除 Cookie”：只删除 cookies.json 和 qrcode.png；这是本地退出，不保证服务器端所有会话立即撤销。为了彻底处理服务端会话，应使用官方知到 App 的账号安全功能。
“删除课程与进度缓存”：只删除 zhidao-courses.json 和 zhidao-progress.json，不清除登录态，不影响知到官方服务器信息。
上述清理操作均需二次确认；软件阻止在自己启动的读取或登录任务仍在执行期间清理。
卸载默认保留 %USERPROFILE%\.zhs 数据目录，以免误删由独立 ZHS 安装或较旧版本共享使用的数据。若你希望清理这些个人文件，须在卸载前自行使用设置页处理。

6. 安全限制
Cookie 尚未采用系统账户专用加密。可访问 Windows 用户文件的程序可能读取明文 Cookie。请保护设备及系统账号，并避免在公共电脑上登录。当前安装包没有数字签名；Windows 真机安装与真实知到账号读取尚未完成独立验收。

7. 版本与更新
本版不自动上传数据，不强制检查更新，不使用激活码。用户可在安装包内查看 GPLv3 全文及脚本源码。正式变更时可能重新提示隐私说明。

8. V4.4 的原版模式
用户可以在单门智慧课程详情中自主切换“ZHS 原版模拟观看心跳”。此模式将直接运行上游 ZHS 命令行，向知到服务器发送进度数据，可能改变课程学习记录，且原版包含视频内弹窗题目处理，并非只读功能。运行前会提示并要求独立确认。
%LOCALAPPDATA%\ZHSDesktop\play-mode.txt 仅保存用户所选模式（official/zhs-original），不含凭证。

9. V5.2 官方 WebView2 播放窗口
用户可在知到官网网页内登录并观看课程。该 WebView2 配置文件保存在 %LOCALAPPDATA%\ZHSDesktop\official-webview-profile，可能包含官网 Cookie、缓存及登录信息，并且不与 ZHS Python Cookie 共享。
播放器仅尝试对官方网页内 HTML5 video 设置正常倍速；不自行向知到平台提交进度或心跳、不注入虚假播放状态。
如需清除网页登录数据，请先关闭全部播放窗口，然后删除此 profile 文件夹；若正在播放请勿直接删除。
WebView2 SDK 来自官方 NuGet 固定版本，Windows WebView2 Runtime 由 Microsoft 维护。

10. V5.2 特别说明
共享课路由标识 recruitAndCourseId 会与课程资料一起保存在本机缓存，不应对外分享缓存文件或诊断截图。异常信息仅显示允许列表内的错误代码，不记录原始请求 URL/Cookie。Windows 重新安装需重新确认本版隐私告知。关闭播放器会将此课只读核验加入队列，清理数据前会等待核验退出。

11. V5.2.7 官方连续播放开关：若用户启用，程序仅在官网顶层课程视频页面选择一个可见主视频，尝试 HTML5 video.play() 并设置倍速；不控制 iframe 内视频。自动下一节仅在明确的课程主内容区域内识别精确按钮文字，无法安全识别时要求手动切换。不会自动答题、提交作业或伪造视频进度。
12. V5.2.9 Beta 1 · 从本机导入已有 ZHS Cookie 文件
用户可自主从本人电脑选择 ZHS 0.1.5 cookies.json，程序在本机检查格式、知到 Cookie 域名、大小和字段，替换本地登录 Cookie 后以只读请求检查服务器是否认可当前登录。检查无法确认登录时尝试恢复导入前的 Cookie。软件不读取浏览器的其他 Cookie、不上传凭证到开发者服务器、不索取账号密码。Cookie 仍按 ZHS 上游格式以明文保存在当前 Windows 用户的 .zhs 目录；本机导入前有明确的二次确认。
这项功能仅支持 ZHS 文件格式，不代表能将浏览器中的任意 Cookie 文本用于登录。用户可以选择继续使用扫码登录。

13. V5.2.9 Beta 2 · 用户在本机直接输入 Cookie
新增 Windows 设置页遮蔽输入框，可由本人主动粘贴知到站点 Cookie 请求头字符串或 ZHS JSON。程序在内存中解析并按 ZHS 原格式写入当前 Windows 用户目录，再由原有 ZHS 服务端只读接口核验登录；若未确认则尝试回滚原凭证。输入不会发到开发者自建服务或写入 GUI 日志；但 ZHS 上游仍将 Cookie 明文保存在本机，用户必须保护该文件。文件导入和扫码登录仍保留。
